# EEG-ZU3EG-Terminal

> 基于 XCZU3EG 的 16 通道 SSVEP 脑机接口终端：识别在 FPGA 内逐帧完成，整机免 PC 独立运行。

面向渐冻症、高位截瘫等重度运动障碍人群的沟通需求，这是一套能自己开机、自己显示、自己说话的脑机接口终端。
自制 16 通道采集板（两片 ADS1299，有线 SPI）接入 Zynq UltraScale+ XCZU3EG：PL 负责采集控制、帧校验、16 通道滤波、
4:1 抽取、频谱计算与 SSVEP 的 eTRCA 在线判决；PS（4×A53 + PetaLinux）运行内核驱动与 Qt 终端，提供示波器、存储回放、
电极接触 / 阻抗检测、拼音打字、离线语音播报，以及实验性的胸部 ECG 模式。

它不是"把脑电搬给 CPU 跑模型"。判决在 PL 内逐帧完成，窗口起点由硬件序号对齐，A53 零负载；
定点流水线与软件模型逐位一致，所以每一次硬件判决都随时可以用软件复核。

# 16 通道脑电帽固定电极映射（已确认）

## 1. 适用范围

本方案是当前 64 导脑电帽的正式固定采集位置，兼顾本项目的两项主要脑机接口任务：

- 运动想象：重点覆盖双侧感觉运动皮层；
- SSVEP：重点覆盖枕叶和顶枕区视觉皮层。

物理连接关系来自 `脑电极引脚与实际ADS1299引脚对应.xlsx`。用户已经确认脑电帽上具备下列全部接口，并决定后续持续使用这组位置。本文件固定“64 导帽上的电极位置”，不修改采集板、ADS1299 或 Zynq 的既有电气连接。

## 2. 固定原则

1. ADS1299-1 的 8 路固定分配给运动想象区域。
2. ADS1299-2 的 8 路固定分配给 SSVEP 区域。
3. 保留左右对称及中线位置，便于运动想象空间特征和 SSVEP 空间滤波。
4. 与软件数据格式固定一致：ADS1299-1 对应软件逻辑 CH01～CH08，ADS1299-2 对应 CH09～CH16。
5. 脑电帽采集线标签 `CH1～CH16` 不是软件逻辑通道号，界面和文件中应优先显示电极名称及软件逻辑通道号。

## 5. REF 与 BIAS 选择

固定配置：

```text
REF  = FCz
BIAS = AFz
```

原因：FCz 可作为两组通道的公共头皮参考，同时不占用 C3、Cz、C4 等运动想象核心采集位；AFz 位于前额中线，适合作为独立 BIAS 电极位置。用户已确认脑电帽具备 FCz 和 AFz，本项目后续固定使用这两个接口。

本项目不再采用 Fp1/Fp2 等替代位置，也不在开发过程中临时交换上述接口；如需眼电功能，应作为独立扩展重新评审，不能改变本固定 16 通道映射。

## 6. 必须区分的三个“地”概念

- 采集板 `AGND`：电路模拟地，可按既定非隔离数字接口方案与 Zynq/FMC 系统 GND 共地。
- Zynq `GND`：数字系统和电平转换的参考地。
- 脑电帽标为 `GND` 的受试者电极：在本项目中接 ADS1299 的 `BIAS` 输出，绝不能接 `AGND` 或 Zynq GND。

受试者连接测试必须采用合适的电池供电或医疗级隔离方案。受试者连接期间，不得让非隔离的市电电源、接地示波器、USB 地或其他台式仪器通过系统形成到人体的接地通路。本系统是竞赛/科研原型，不是医疗诊断设备。

## 7. 阻抗检测注意事项

- 16 个 P 侧采集电极可分别通过两片 ADS1299 的 `LOFF_SENSP` 规划检测。
- 所有 N 侧共用 SRB1 时，公共参考电极不是 16 个独立 N 侧电极；手册指出 referential montage 对参考电极只使用一个 lead-off 电流源。
- 脑电帽 `GND/BIAS` 的检测不能按普通 EEG 通道处理。ADS1299 手册说明，BIAS 上电 lead-off 检测要求 BIAS 放大器关闭；正常工作时只能按手册规定监测 BIAS 输出比较器状态。
- 当前前端 `4.7 kΩ + 4.7 nF` 网络参与检测路径。板级标定前应显示“连接状态/通道等效阻抗”，不应宣称得到纯电极阻抗。

## 8. 固定映射核对

本方案已经确认并写入项目上下文。接线、软件元数据和 Qt 标签必须持续核对以下事项：

1. 采集线标签 CH1～CH16 与本表记录完全一致；
2. 软件通道显示按 CH01～CH16 和电极名称映射，不按采集线标签误排；
3. 受试者电极 `GND` 确实接 BIAS，而非采集板 AGND；
4. 任何代码、数据文件、Qt 标签或报告均引用本表，不得自行建立第二套顺序。

本映射为项目正式配置。若未来确需变更，必须同步更新本文件、Excel、软件元数据、测试黄金数据和项目文档，并重新进行评审；未经变更记录，不得改线或改通道定义。

# 案例模板：对协议敏感的指标结论（protocol-sensitive claim）

**适用场景**：报告识别准确率、ITR、延迟、增益等会随评估协议变化的数字。**用法**：每个数字必须带一张“协议卡”，并在部署协议下给出主结果。
**已验证效果**：案例 07——同一方案在不同窗口起点下收益从 +0.28 到 +4.25 个百分点，只有带协议卡才看得出差别。**失效条件**：部署协议本身不固定时，需要先固定协议。

```markdown
## 协议卡
| 项 | 值 | 与部署一致吗 |
| --- | --- | --- |
| 数据集 / 被试数 | 清华 S1–S10 | 公开数据 |
| 目标子集 | 40 中取 28（round(i*40/28)） | 是 |
| 通道 | 后部 8 导 | 是 |
| 窗口起点 | 刺激起点后 122 帧（0.4997 s） | 是（部署值） |
| 检查点 / 窗长 | 60 90 122 183 244 305 366 488 帧 | 是 |
| 校准量 | 3 轮 | 是 |
| 阈值来源 | 重代入 / 留一（两种都报告） | 重代入为板上实际 |
| 判决规则 | 连续 2 个检查点一致 | 是 |
| ITR 计算 | Wolpaw，28 目标，含 0.5 s 视线转移 | 约定 |

## 主结果（部署协议）
| 方案 | 固定窗准确率（各窗长） | 动态判决：已决策 / 决策内准确率 / 总准确率 / 平均时长 / ITR |
| --- | --- | --- |

## 敏感性（改变一项，其余不变）
| 改变 | 结果变化 | 结论是否依然成立 |
| --- | --- | --- |
| 窗口起点 0.5 s → 0.14 s | +0.28 → +4.25 个百分点 | 取决于起点 |

## 声明范围
- 本结论只在上述协议下成立；其他协议未测。
```
